# 2d Image Viewer
This Vulkan 2D image viewer is a basic loader using stb image. The shader files are included and all required is to change the image file in the directory and change the main function.
## Purpose
The purpose of this repository is to showcase my learning around the Vulkan API and to create a less hard coded project.
## Notes
* This was made in Eclipse IDE
* Uses stb image and GLFW
* Has shader files included
* Uses the Vulkan Template repository as base
* Example image is of a Vulkan triangle
